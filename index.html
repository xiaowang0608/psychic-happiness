🎓 大学五年规划

生物制药技术 · 高本贯通 · 9月报考英语四级 · 考研方向（生物/药学）

总体目标

5年主线：夯实专业基础 → 通过英语四级 → 准备考研（生物化学/微生物与生化药学/药学方向）
辅线：科研经历、实习、竞赛、社团、社会实践

分阶段规划

大一 · 适应启航（2026.09 - 2027.07）
📍 核心：适应大学 + 打好学业基础 + 探索兴趣方向
  • 专业课：生物化学、分子生物学、微生物学、细胞生物学、有机化学
  • 9月：报名英语四级，每天背30-50个四级词汇
  • 加入1-2个社团（建议：英语社 / 街舞社 / 生物兴趣社）
  • 熟悉图书馆、实验室预约流程
  • 目标：绩点3.0+，四级425+
大二 · 蓄力成长（2027.09 - 2028.07）
📍 核心：四级冲刺 + 开始接触科研
  • 6月：英语四级考试（争取500+）
  • 主动联系导师，争取进实验室做助研
  • 参加"挑战杯"、"互联网+"、"全国大学生生命科学竞赛"等
  • 确定考研方向（建议：微生物与生化药学 / 药学 / 制药工程）
  • 绩点目标3.3+
大三 · 决胜冲刺（2028.09 - 2029.07）
📍 核心：考研备考 + 完成毕业论文
  • 开始系统复习：政治 + 英语 + 专业课（生物化学/药学综合）
  • 确定目标院校（建议：药学211/985 或 中国药科大学/沈阳药科大学）
  • 完成毕业实习，积累实践经验
  • 关注目标院校考研招生简章
大四 · 考研决战（2029.09 - 2030.06）
📍 核心：全力备考 + 12月考研初试
  • 9-12月：考研冲刺（每天6-8h学习）
  • 12月底：考研初试
  • 次年2-3月：出成绩、准备复试
  • 6月：本科毕业
大五 · 研究生阶段（2030.09 起）
📍 核心：读研深耕（视个人情况，本规划供参考）
  • 研究生一年级：上课 + 文献阅读 + 确定研究方向
  • 研究生二、三年级：发论文 + 实习 + 毕业
  • 目标：进入药企研发岗 / 医院药剂科 / 继续读博

必学技能

时间管理（四象限/番茄钟）基础
英语四级词汇4500 + 听力阅读必备

🦵 关节黑 + 肚子黑改善方案

关节
黑
膝盖/手肘/屁股黑
原因：摩擦+老废角质堆积
每周2次去角质（身体磨砂膏+手揉3分钟）
洗完澡立刻涂身体乳（含烟酰胺/果酸）
穿裤子避免摩擦（少穿超短裙配长靴）
推荐：凡士林身体乳 / olay烟酰胺身体乳 / alpha果酸身体乳
肚子
黑
肚子黑（腹黑线/黑棘皮）
原因：可能是激素、摩擦、胰岛素抵抗
每天涂身体乳+轻轻按摩（5分钟）
减脂（腹部脂肪减少会变淡）
避免紧身裤/勒腰带
严重建议看内分泌科

🌟 雀斑改善方案

1. 防晒是第一位！每天涂防晒霜（SPF30+ PA+++），即使阴天
2. 美白成分：烟酰胺、维C、传明酸、377
3. 精华推荐：The Ordinary烟酰胺、olay小白瓶、修正淡斑霜
4. 多吃维C：柠檬水、番茄、猕猴桃
5. 不熬夜，11点前睡觉
6. 医美（快速）：光子嫩肤、皮秒激光（严重时考虑）

💇 细软塌发质改善

洗发：2天洗一次（不要每天洗），用控油蓬松洗发水
· 推荐：海飞丝无硅油、吕（Ryo）绿吕、馥绿德雅
护发：护发素只涂发尾，避开头皮
吹发：逆着发根吹，头顶蓬松感立刻出来
蓬松技巧： · 倒梳头顶发根
· 玉米须夹板蓬松发根
· 用蓬松喷雾（如Lush或免洗喷雾）
饮食：黑芝麻、核桃、蛋白质（头发喜欢）
发型推荐：锁骨发+八字刘海、高马尾、丸子头
